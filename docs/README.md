## 本文档的约定

- 示例中的路径，除特别说明外都相对于 Web 根目录。
- `dt` 一律指**秒**，与运行时各时钟的期望一致。
- 坐标一律是 **UI 单位** —— 原点在 UI 左上角、y 轴向下 —— 除非文中明确写了
  "设备像素"或"屏幕空间"。
